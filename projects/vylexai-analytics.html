Project Overview

At a Glance

Goal

Give the team one trusted place to track how the project is doing — across contributors, network, investors, and overall health — instead of scattered, manual reports.

Stack

FastAPI backend and a Next.js frontend, reading from a PostgreSQL database, all containerized with Docker.

Scope

Automated metric jobs, validated REST APIs, dashboard pages, and an automated weekly investor PDF report.

Engineering

Read-only database access, CI checks, Docker setup, and validation-focused backend workflows keep the data trustworthy.

How It Works

From Data to Decisions

  1. 01

    Read-Only Access

    Connect to the source PostgreSQL database with read-only access — safe by design.

  2. 02

    Metric Jobs

    Automated jobs compute contributor, network, investor, and health metrics on a schedule.

  3. 03

    REST API

    FastAPI exposes the computed metrics through validated, typed REST endpoints.

  4. 04

    Dashboards

    Next.js dashboard pages turn the API data into clear, interactive views.

  5. 05

    Investor PDF

    A weekly investor report is generated automatically and shipped as a polished PDF.

  6. 06

    CI & Docker

    CI checks and a Docker setup keep every change validated and reproducible.

What It Tracks

Four Metric Domains

Every domain has its own jobs, endpoints, and dashboard views, so each audience — the team, the community, and investors — sees the numbers that matter to them.

Contributor

Activity and engagement across the people building and maintaining the project.

Network

How the broader network is growing, connecting, and interacting over time.

Investor

The metrics investors care about, packaged into an automated weekly PDF report.

Health

Overall project health signals that flag what's trending up and what needs attention.

Under the Hood

Engineering Highlights

Read-Only Data Access

The platform never mutates source data — a read-only connection keeps production safe while metrics are computed.

Validation-First Backend

Workflows are built around validation, so bad or unexpected data is caught before it reaches a dashboard or report.

CI Checks

Continuous integration runs checks on every change, keeping the codebase stable as the platform grows.

Dockerized Setup

Backend and frontend run in Docker, making the platform reproducible across local, CI, and deployment environments.
